# Asset manifest — Ten Candles

Spec §14. Written by hand on 2026-09-15 at the start of Phase 4, before any Phase 4 tower or enemy code. `Tools/Ten Candles/Asset Inventory` (`Editor/AssetInventoryTool.cs`) doesn't exist yet. It will regenerate this file once the art decisions below are made.

**Statuses**

- **Covered:** real art is wired to the id.
- **Placeholder:** the id plays with generated or stand-in art.
- **No art:** nothing in the project fits the id.
- **Not implemented:** no data asset exists for the id yet.

## Unassigned art

### In the project

- **None of the pack art is unassigned.** Every Craftpix folder is used by a spec id.
- **`Craftpix/Party/candle_full.png`** isn't referenced by any scene, prefab or data asset. It looks superseded by `candle_wax` + `candle_flame`.
- **11 of the 17 `Art/Placeholder` shapes** aren't referenced by the built scene or data: balloon, cake, candle, candle_tower, cannon, flame, floor, gift, lantern, rocket, triangle. They are regenerated by `PlaceholderArt.CreateAll` each time the scene is built. They are tooling output, not unassigned art.
